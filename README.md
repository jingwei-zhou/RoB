# 买房还是租房？全成本计算器 · Rent vs Buy Calculator

一个把买房的所有隐性成本、2026 年美国联邦税务规则和机会成本都算进来的租买对比工具。中英双语，纯静态网页，所有计算在浏览器里完成。

A full-cost, after-tax rent-vs-buy calculator for the U.S. Bilingual (中文 / English), a single static HTML file, and everything runs in the browser.

## 功能 · Features

- 月度摊销引擎，逐年比较买房与「租房＋投资」两条路的税后净资产
- 2026 年联邦税务规则（OBBBA）：标准扣除、SALT 上限及收入递减、2030 年回到 $10K、房贷利息 $750K 上限、PMI 抵扣、自住房 $250K / $500K 增值豁免
- 报税身份、州所得税率、新泽西式州地税抵扣均可设置；联邦边际税率与资本利得税率按收入自动估算
- 盈亏平衡年、打平所需房价涨幅与月租、敏感性矩阵、逐年明细
- 参数自动写入网址，「复制分享链接」即可把你的场景发给别人
- 深色模式、手机适配

## 部署 · Deploy

仓库根目录只有 `index.html`，开启 GitHub Pages（Settings → Pages → Deploy from a branch → `main` / root）即可上线。

The repo is just `index.html`. Enable GitHub Pages (Settings → Pages → Deploy from a branch → `main`, root) and it's live.
